# ターボフレンズ

ともだちとオンラインで遊べる3Dカートレース（ブラウザ・キーボード操作）。キャラ・コース・アイテムはすべてオリジナルです。

- 2〜4人でオンライン対戦（空き枠はCPU）
- 3コース：そよかぜ草原 / サンサン砂漠 / ネオン夜の街
- 9キャラ（クセの強いカート組6人＋自分の足で走る3人。性能がそれぞれ違う）、6種類のアイテム、ドリフト、スタートダッシュ

## あそびかた
1. 部屋を作る人が「部屋を作る」を選ぶ
2. 表示された招待URL（Cキーでコピー）か4文字の部屋コードをともだちに送る
3. 全員の準備OKがそろったら、部屋を作った人がスタート

通信はPeerJSを使ったP2P方式です（部屋を作った人のPCが親）。親はレース中ブラウザのタブを表示したままにしてください。

## 操作
| キー | 操作 |
|---|---|
| ↑ / W | アクセル |
| ↓ / S | ブレーキ・バック |
| ← → / A D | ハンドル |
| Space / Shift | ドリフト |
| X / E | アイテム（↓と同時で後ろへ） |
| Esc | レースをやめる |
| M | 音のオン・オフ |

### ゲームコントローラー
A / RT アクセル、B / LT ブレーキ、左スティック・十字キー ハンドル、LB / RB ドリフト、X / Y アイテム（スティック下で後ろへ）、START やめる。メニューは十字キーとA（けってい）・B（もどる）。
